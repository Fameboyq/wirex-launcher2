# Wirex Launcher 2.0

Официальный исходный код полнофункционального лаунчера **Wirex Client** (версия Minecraft 1.21.4 Fabric), полностью идентичный релизной сборке `v1.0`.

---

## Архитектура и стек

- **C# / WPF (.NET Framework 4.8 / Roslyn)**: Нативная оболочка с поддержкой безрамочного окна, плавного перемещения (`WM_NCLBUTTONDOWN`), автономного HTTP-сервера статики и запуска игрового процесса.
- **Microsoft WebView2**: Встроенный движок рендеринга Chromium с аппаратным ускорением и изоляцией.
- **React 18 + Tailwind / Vite (WebUI)**: Премиальный Glassmorphism-интерфейс в тёмных тонах с поддержкой профилей, слайдеров выделения оперативной памяти (до 16 ГБ), карточек клиента и анимированных статусов.
- **Supabase Cloud Database**: Авторизация по логину/почте, проверка ролей (Dev/Admin/Member), автоматическая валидация и продление подписки, авторегистрация новых пользователей.
- **Fabric KnotClient Launcher**: Автоматическое определение установленной Java 21 (или фоновая загрузка OpenJDK 21), скачивание и распаковка `WirexClient.zip` из официальных релизов GitHub, сборка аргументов запуска и запуск Minecraft.

## Сборка из исходников

Для сборки проекта выполните:

```cmd
build.bat
```

Скрипт автоматически найдёт компилятор C# (Roslyn / MSBuild) и скомпилирует автономный исполняемый файл:
`bin\Release\WirexLauncher.exe` (копируется также в корень репозитория).
Все зависимости (WebView2 DLLs, WebView2Loader.dll, React WebUI) вшиваются внутрь исполняемого файла в виде внедрённых ресурсов (Embedded Resources).
